# DecoDXLog 1.17.21

## Italiano

Questa versione allinea il fork alla 1.17.21 di upstream e corregge alcuni problemi introdotti nella linea 1.17.20.

- Corretta l’importazione ADIF: dopo la selezione del file l’anteprima viene mostrata correttamente e il pulsante «Importa» avvia davvero l’operazione.
- Ripristinata la scheda inferiore con Diplomi, Statistiche, QSL, Attività, Cluster e Propagazione.
- Corrette le finestre di anteprima importazione e diagnostica integrazioni con il tema Ocean Blue.
- Corretti alcuni indicatori di diplomi e QSL che restavano visibili senza contenuto.
- Mantenuta la copertura funzionale della 1.17.20: guida iniziale, importazione ADIF con anteprima, backup/ripristino, QSL, diagnostica, attivazioni, cloud e controlli di release.
- Aggiornate le traduzioni in tutte le lingue supportate.
- Aggiunti test QML per importazione, FileDialog e finestre coerenti con il tema.

## English

This release aligns the fork with upstream 1.17.21 and fixes issues introduced in the 1.17.20 line.

- Fixed ADIF import: after choosing a file, the preview is displayed correctly and the “Import” button now starts the operation.
- Restored the bottom tab containing Awards, Statistics, QSL, Activity, Cluster and Propagation.
- Fixed the import preview and integration diagnostics windows when using the Ocean Blue theme.
- Fixed award and QSL indicators that could remain visible without content.
- Preserved the 1.17.20 feature set: first-run guide, ADIF preview import, backup/restore, QSL, diagnostics, activations, cloud and release gates.
- Updated translations in all supported languages.
- Added QML tests covering import actions, `FileDialog` imports and theme-consistent windows.
